# 接口设计

## 1. 设计原则

1. **Target 是一等公民**。所有截图/操作都带 `target_id`，没有"隐式当前窗口"。
2. **默认用图像坐标**。Agent 看到的是图，点也应该按图点；服务端负责换算。高级调用方可显式指定 `space: "client" | "screen" | "css"`。
3. **能力可发现**。每个 target 返回 `capabilities`，调用方据此选择策略；失败时返回结构化原因而不是含糊的 "failed"。
4. **默认稳定**。截图/操作默认等待画面稳定；需要"立即"时显式关闭。
5. **幂等与可恢复**。`close`、`panic` 幂等；`screenshot` 无副作用；所有资源有 TTL。
6. **图像优先但可落盘**。MCP 返回 image content；HTTP 返回二进制；都可选保存到指定路径。
7. **MCP 与 HTTP 同语义**。工具名与参数一一对应，便于其它语言客户端接入。

```json
  "window": {
    "hwnd": "0x000A1B2C",
    "rect": [1800, 40, 900, 640],
    "client": [1808, 71, 884, 601],
    "dpi_scale": 1.5,
    "dpi_awareness": "PerMonitorAware"
  },
  "warnings": [],
  "park": { "mode": "offscreen", "original_rect": [120, 80, 900, 640], "original_state": "normal" },
```

## 3. MCP 工具

> **实现状态（2026-10-24 / 0.3.1-beta）**：MCP stdio 已实现 **21 个不带 `gs_` 前缀的工具**：
> `list_windows / attach_window / open_web / attach_cdp / list_targets / screenshot / snapshot / observe / click / click_element / scroll / drag / key / set_text / navigate / viewport / console / network / get_html / close_target / close_all`。
> 原生窗口 target 与无头 Edge web target 共用同一套工具；`kind` 区分 `app` / `web`，不适用时返回 `TARGET_KIND_MISMATCH`。
> `attach_cdp` 连接已有 Chromium/Electron DevTools 端口，`external=true`，`close_target` 只 detach，不关闭外部浏览器。
> `screenshot` 的 `full_page` / `clip`、`snapshot`、`navigate`、`viewport`、`console`、`network`、`get_html` 为 web-only。
> MCP 客户端按 server 命名空间隔离工具，因此不必加前缀；下文 `gs_` 是最终接口草案，v1.0 再统一。
> HTTP/WS 接口尚未实现；当前可用接口只有 CLI 与 MCP stdio。

> 命名统一 `gs_` 前缀。MCP 结果：图像工具返回 `image` content + 一段 JSON 文本；其余返回 `structuredContent`。
> 只读工具带 `readOnlyHint: true`；会改变目标状态的工具带 `destructiveHint: true`，便于客户端做权限提示。

### 3.1.1 Web 截图与诊断（实际实现）

- `screenshot { target_id, full_page?, clip? }`：默认截视口；`full_page` 按 `Page.getLayoutMetrics` 的 CSS 内容尺寸截整页；`clip {x,y,width,height}` 按 CSS 像素裁剪，两者互斥。超过 16384px 返回 `CAPTURE_TOO_LARGE`。元数据 `region` 为 `viewport|full_page|clip`；截图后恢复调用方视口。
- `snapshot { target_id, viewports?, full_page? }`：默认 390×844@2 移动、768×1024、1440×900，最多 6 个；返回一段 text JSON（每个 `shots[i]` 的视口、图像尺寸、hash、`horizontal_overflow`、`scroll_width`、最多 5 个越界元素）+ 按 index 顺序的 PNG。
- `network { target_id, limit? }`：返回 `Network.loadingFailed`（`kind:"failed"`，含 error/type/url）与 HTTP 4xx/5xx（`kind:"http_error"`，含 status），最多 200 条。
- 导航在 `readyState=complete` + fonts.ready 后最多等 3s 网络静默（300ms 无在途请求）；超时不失败。
- web 坐标始终是 CSS 像素；`clip` 只接受坐标，不接受 selector（先用 `observe` 取 bounds）。


```json
{

  "args": [],
  "cwd": null,
  "env": {},
```

### 3.3 `gs_attach`

```json
{ "hwnd": "0x000A1B2C", "confirm": true, "hide_from_taskbar": true }
```

- 接管**已有**窗口会移动人的窗口；必须 `confirm:true`，daemon 会弹托盘通知。
- 默认关闭"接管"能力（配置项 `allow_attach=false`），防止 Agent 滥动用户的窗口。

### 3.4 `gs_screenshot`

```json
{
  "target_id": "tgt_7f3c2a",
  "region": [0, 0, 800, 600],          // 图像坐标；缺省为整张
  "max_width": 1568,                    // 默认 1568；null/0 = 原始尺寸
  "format": "png",                      // png | jpeg
  "wait_stable_ms": 250,                // 0 = 不等待
  "include_cursor": false,
  "include_frame": false,
  "save_to": null
}
```

返回 image + metadata。`save_to` 时同时返回绝对路径（路径必须在允许的目录内，默认仅 `%TEMP%\GhostScreen\shots`）。

### 3.5 `gs_observe`

```json
{
  "target_id": "tgt_7f3c2a",
  "kind": "auto",                       // auto | uia | dom
  "interactive_only": true,
  "max_nodes": 300
}
```

返回元素列表（见 2.2）。`kind:"dom"` 仅 web target 可用。

### 3.6 `gs_click`

```json
{
  "target_id": "tgt_7f3c2a",
  "x": 412, "y": 208,                   // 图像坐标（默认）
  "ref": null,                          // 或 "e12"
  "selector": null,                     // 或 CSS selector（web）
  "button": "left",                     // left | right | middle
  "clicks": 1,
  "modifiers": [],                      // ["CTRL","SHIFT","ALT"]
  "space": "image",                     // image | client | screen | css
  "settle": true
}
```

三选一：`(x,y)` / `ref` / `selector`。返回：

```json
{
  "ok": true,
  "strategy": "message",
  "focus": "not-needed",
  "resolved_point": { "image": [412, 208], "client": [405, 181], "screen": [2213, 252] },
  "changed": true,
  "likely_noop": false,
  "settled_ms": 180
}
```

- 原生元素动作先按 UIA bounds 找 HWND 子控件，走 `BM_CLICK`/`WM_*`；没有 HWND 时自动走 UIA（Invoke/Toggle/SelectionItem/ExpandCollapse；文本用 ValuePattern）并恢复前台。
- `strict_no_focus_steal: true` 时，需要 UIA 的动作返回 `FOCUS_STEAL_NOT_ALLOWED` 而不执行；默认 false。
- 坐标点击：有可点击 HWND 子控件走消息；WPF/UWP 单 HWND 用 UIA `AtPoint` 找最小可执行元素并恢复前台；`strict_no_focus_steal` 同样适用。
- 控件没有任何可执行 pattern 时返回 `ELEMENT_NOT_ACTIONABLE`；这是最后兜底。
- 成功但前台未恢复时 `focus:"stolen"`，同时返回 `FOCUS_STOLEN` 警告（`isError:true`；动作已执行，不要盲目重试）。

### 3.7 `gs_type`

```json
{
  "target_id": "tgt_7f3c2a",
```

### 3.10 `gs_wait_for`

```json
{
  "target_id": "tgt_7f3c2a",
  "condition": { "type": "stable", "quiet_ms": 300 },
  "timeout_ms": 5000
}
```

条件类型：

| type | 参数 | 说明 |
|---|---|---|
| `stable` | `quiet_ms` | 画面静止 |
| `pixel_change` | `region`, `threshold` | 指定区域变化 |
| `element` | `selector` / `name` / `role` | 元素出现 |
| `text` | `text`, `exact` | 页面/窗口出现文本（web 用 DOM；app 用 UIA） |
| `network_idle` | `idle_ms` | 网页网络空闲 |
| `js` | `expression` | 网页条件为真 |

### 3.13 `gs_web_snapshot`（便捷层）

```json
{
  "url": "http://localhost:3000",
  "viewports": [
    { "name": "mobile",  "width": 390,  "height": 844,  "dpr": 3 },
    { "name": "tablet",  "width": 768,  "height": 1024, "dpr": 2 },
    { "name": "desktop", "width": 1440, "height": 900,  "dpr": 1 }
  ],
  "full_page": true,
  "max_width": 1200,
  "check_overflow": true
}
```

返回：每个视口一张图 + 每张图的诊断（console errors、失败请求、横向溢出元素 selector）。内部复用 `gs_open`/`gs_screenshot`/`gs_console`/`gs_network`，结束后自动关闭。

### 3.14 `gs_close` / `gs_panic`

```json
{ "target_id": "tgt_7f3c2a", "mode": "restore" }   // restore | terminate
```

- `restore`：接管的人窗口还原位置；自建进程仍保留（由 `terminate` 明确关闭）。
- `terminate`：终止我们启动的进程树，并还原样式。
- `gs_panic`：无参数；停止所有输入、关闭所有 target、还原、清空队列。幂等。

## 4. HTTP / WebSocket API

Base：`http://127.0.0.1:<port>/v1`，端口随机，写入 `%LOCALAPPDATA%\GhostScreen\daemon.json`。
认证：`Authorization: Bearer <token>`；WS 用 `Sec-WebSocket-Protocol: gs.<token>` 或查询参数。
CORS：默认关闭；仅允许 `http://127.0.0.1:<port>` 自身。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 状态页（HTML，1s 轮询；需 token） |
| GET | `/api/status` | 实现版：版本/pid/uptime/恢复摘要/targets（需 token） |
| GET | `/api/screenshot?target_id=` | 实现版：单 target PNG（原生 2s / web 6s 上限；hung 409、超时 504） |
| POST | `/api/panic` | 实现版：close_all（需 token） |
| GET | `/health` | 健康检查（无需 token，仅返回版本/uptime） |
| GET | `/targets` | 列表 |
| POST | `/targets` | 创建（body 同 `gs_open`/`gs_attach`） |
| GET | `/targets/{id}` | 详情 |
| DELETE | `/targets/{id}?mode=restore` | 关闭 |
| POST | `/targets/{id}/capture` | 截图；返回 `image/png`，元数据在 `X-GS-Meta`（base64 JSON）或 `?meta=1` 时返回 JSON |
| POST | `/targets/{id}/actions` | 批量动作（点击/输入/按键/滚动/等待） |
| GET | `/targets/{id}/stream` | WS：JPEG 帧（二进制）+ 状态事件（文本） |
| POST | `/targets/{id}/observe` | 观测 |
| GET | `/targets/{id}/console` | 网页 console |
| GET | `/targets/{id}/network` | 网页网络 |
| GET | `/events` | SSE：target 状态、错误、审计事件 |
| POST | `/panic` | 急停 |
| GET | `/audit?limit=200` | 审计日志 |

> **实现状态（0.3.0-dev）**：只实现了 `/`、`/api/status`、`/api/screenshot`、`/api/panic`，且只绑 127.0.0.1、每次启动随机 token；其余是草案。token 可通过 `?token=` 或 `X-GhostScreen-Token` 头传递；端点信息写在 `%LOCALAPPDATA%\GhostScreen\status.json`。缩略图刷新为 5s（0.2fps）。

**动作批量接口**（减少往返）：

```json
{
  "actions": [
    { "type": "click", "ref": "e12" },
    { "type": "type", "text": "hello", "submit": true },
    { "type": "wait_for", "condition": { "type": "stable" }, "timeout_ms": 3000 }
  ],
  "stop_on_error": true
}
```

返回逐步结果数组；每步都带 `ok/strategy/changed/error`。

**WS 帧协议**

- 二进制帧：JPEG 数据，前缀 1 字节保留（0x00）。
- 文本帧：`{"type":"state","target":...}`、`{"type":"error",...}`、`{"type":"action",...}`。
- 客户端可发 `{"type":"set_fps","fps":2}`、`{"type":"pause"}`。

## 5. CLI

```bash
gs daemon                      # 启动守护进程（--tray 可带托盘）
gs status                      # 健康/版本/端口/token 位置
gs mcp                         # stdio MCP 服务器（给 Agent 客户端）
gs doctor [--bundle]           # 环境自检；--bundle 生成脱敏诊断包
gs list                        # 可接管窗口
gs open --url http://localhost:3000 --viewport 1280x800
gs open --app notepad.exe
gs targets
gs shot <id> --out shot.png --max-width 1568
gs observe <id> --interactive
gs click <id> --x 412 --y 208
gs click <id> --ref e12
gs type <id> "hello 世界" --submit
gs key <id> CTRL S
gs scroll <id> 400 300 0 -600
gs wait <id> stable --timeout 5000
gs eval <id> "document.title"
gs close <id> --terminate
gs ui                          # 打开极简状态页
gs version
gs panic
```

所有命令支持 `--json`，便于脚本/CI。CLI 与 daemon 通过命名管道通信；未启动时给出明确提示（`DAEMON_NOT_RUNNING`）。`gs doctor` 输出检查项、结论与下一步命令；`--bundle` 只在用户主动执行时收集脱敏日志（无遥测）。

## 6. 错误模型

| 码 | 含义 | 建议处理 |
|---|---|---|
| `TARGET_NOT_FOUND` | target 不存在/已关闭 | 重新 list/open |
| `TARGET_STATE_INVALID` | 当前状态不允许该操作 | 等待 ready 或 close |
| `NOT_RENDERABLE` | 最小化/隐藏/cloak | 恢复窗口后重试 |
| `PROTECTED_CONTENT` | 设置了 WDA_EXCLUDEFROMCAPTURE | 不支持，换 target |
| `CAPTURE_UNAVAILABLE` | 没有可用后端 | 检查 capabilities |
| `CAPTURE_FAILED` | 后端异常 | 重试一次；仍失败则报告 |
| `CAPTURE_TIMEOUT` | PrintWindow 在超时内未返回，目标可能挂起 | 可重试一次；连续 2 次后 target 会 `TARGET_HUNG` |
| `TARGET_HUNG` | 目标无响应（attach 前拒绝），或连续超时已降级 | close 后重新 attach；内存 ref/epoch 需重新 observe |
| `BLANK_FRAME` | 全黑/纯色 | 换后端或恢复窗口 |
| `STALE_FRAME` | 画面疑似未更新 | 增大 settle；换后端 |
| `ELEMENT_STALE` | ref 的 epoch 过期 | 重新 observe |
| `ELEMENT_NOT_FOUND` | 找不到元素 | 重新 observe / 换 selector |
| `INPUT_UNSUPPORTED` | 该 target 无合适的后台输入方式 | 换语义动作；或请求 interactive |
| `FOCUS_STEAL_NOT_ALLOWED` | 传了 `strict_no_focus_steal=true`，且动作需要 UIA | 关闭 strict；或改用坐标/消息动作 |
| `ELEMENT_NOT_ACTIONABLE` | 控件没有 Invoke/Toggle/SelectionItem/ExpandCollapse/Value 等可执行 pattern | 换控件；用坐标点击；或先让应用进入可操作状态 |
| `FOCUS_STOLEN` | 动作已完成，但前台窗口未能恢复 | 不要盲目重试；提示用户点回原窗口，并检查日志；动作本身已执行 |
| `FOCUS_REQUIRED` | 只能通过 SendInput 完成，且未授权 | 显式开启 interactive |
| `ELEVATED_TARGET` | 目标进程完整性级别更高 | daemon 提权或放弃 |
| `LAUNCH_FAILED` | 进程启动/找不到窗口 | 检查路径/参数/单实例 |
| `PARK_UNSTABLE` | 窗口反复跑回屏幕 | 换 VDD 或放弃 |
| `BROWSER_NOT_FOUND` | 没有 Edge/Chrome | 安装浏览器或配路径 |
| `BROWSER_LAUNCH_FAILED` | Edge 启动失败或未暴露 DevTools 端口 | 检查安装/权限/杀软；重试 |
| `WEB_LAUNCH_FAILED` | 建立 web target 失败（连接/视口/导航前的非超时错误） | 查看 message；重试或换 URL |
| `NAVIGATION_TIMEOUT` | 页面在超时内未达到 readyState=complete | 增大 timeout_ms；检查站点 |
| `CDP_CONNECT_FAILED` | 连接已有 DevTools 端口失败（无权/端口不对/目标不是 Chromium） | 检查启动参数 `--remote-debugging-port` 与端口 |
| `TARGET_CLOSED` | 外部浏览器/窗口已消失，连接已断 | close 后重新 open/attach |
| `STATE_WRITE_FAILED` | 崩溃恢复日志写入失败，attach/open 已撤销 | 检查 `%LOCALAPPDATA%\GhostScreen\state` 权限/磁盘 |
| `TARGET_KIND_MISMATCH` | 对 web target 用了原生-only 参数（或反之） | 查看 target `kind`；改用对应工具/参数 |
| `TIMEOUT` | 等待条件超时 | 增大超时/检查条件 |
| `QUOTA_EXCEEDED` | 超过并行 target/帧率限制 | 关闭空闲 target |
| `PERMISSION_DENIED` | token/授权/接管未确认 | 检查授权 |
| `DAEMON_NOT_RUNNING` | CLI/MCP 连不上 daemon | 启动 daemon |
| `INTERNAL` | 未预期异常 | 带 trace id 上报日志 |

## 7. 坐标、图像与 DPI 约定

**0.2.0-p0 实际实现（先看这段）：**

1. **原生 target**：默认截图是**客户区裁剪**，图像像素 = 客户区物理像素；`click/scroll/drag` 的 `x/y` 直接用图像像素，服务端 `ClientToScreen` 后投递窗口消息。
2. **web target**：`click/scroll/drag` 的 `x/y` 是 **CSS 像素**；截图图像是设备像素，`image = css × device_scale_factor`。截图元数据带 `css_width/css_height/image_scale/device_scale_factor`。默认 DPR=1，此时两者相同。
3. **web 元素**：`observe` 返回 `refId/role/name/selector/bounds(CSS px)/enabled`；`click_element`、`set_text` 用 ref，服务端在点击时重新计算元素中心，滚动后仍有效。
4. **不变量**：原生截图坐标与 `observe` 的 bounds 都是客户区坐标，二者可直接互用。

**最终接口草案（未全部实现）：**

1. **默认 `space:"image"`**：坐标基于当前返回的截图（缩放后的图像像素）。
2. 元数据里的 `image_scale` 是"原图 → 返回图"的比例；`client_origin_in_image` 是客户区左上角在返回图中的位置。
3. 服务端换算：`client = (image - client_origin_in_image) / image_scale`；再 `ClientToScreen`。
4. 网页：图像像素是设备像素；CDP 用 CSS 像素，故 `css = image / (dpr * image_scale)`。
5. `gs_screenshot` 与后续 `gs_click` 之间如果窗口尺寸变化，`ref`/坐标都可能失效；服务端会在元数据里带 `viewport_stamp`，操作时校验，不一致返回 `ELEMENT_STALE` 或要求重新截图。
6. 原生窗口的边框/标题栏默认不计入图像；`include_frame:true` 时图像包含整个窗口，`client_origin_in_image` 仍可用于换算。
7. 高 DPI：daemon 为 PerMonitorV2，所有内部坐标用物理像素；对外元数据带 `dpi_scale`。

## 9. 安全约定（接口层）

- 除 `/health` 外全部要求 token。
- 拒绝 `Origin` 不在白名单的浏览器请求；WS 校验 `Origin` 与子协议 token。
- `gs_attach` 默认关闭；`interactive` 输入默认关闭；两者都需要 daemon 配置显式开启。
- `save_to` 限制在允许目录内，拒绝 `..` 与符号链接逃逸。
- 任何接口都不提供"整屏截图"；`gs_list_windows` 只返回元数据，不返回像素。
- 所有响应带 `X-GS-Trace`，便于对日志。

## 10. 一个完整会话（前端视觉验证）

```text
1. gs_open {kind:"web", url:"http://localhost:3000", viewport:{1280,800,1}}
   → {target_id:"tgt_web01", state:"ready"}

2. gs_screenshot {target_id:"tgt_web01", wait_stable_ms:300}
   → image(1280×800) + {backend:"cdp", stable:true}

3. gs_observe {target_id:"tgt_web01", kind:"dom", interactive_only:true}
   → [{ref:"e3", role:"button", name:"登录", selector:"#login"}]

4. gs_click {target_id:"tgt_web01", selector:"#login"}
   → {ok:true, strategy:"cdp", changed:true}

5. gs_wait_for {target_id:"tgt_web01", condition:{type:"network_idle"}, timeout_ms:5000}
   → {ok:true}

6. gs_screenshot {target_id:"tgt_web01"}
   → image + metadata（用于模型视觉验证）

7. gs_console {target_id:"tgt_web01", levels:["error"]}
   → []

8. gs_set_viewport {target_id:"tgt_web01", width:390, height:844, dpr:3, mobile:true}
9. gs_screenshot {target_id:"tgt_web01"}          # 移动端复验
10. gs_close {target_id:"tgt_web01", mode:"terminate"}
```

全程没有窗口出现在屏幕上，也没有移动人的鼠标/焦点。
