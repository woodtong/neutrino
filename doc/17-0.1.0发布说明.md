## 新增（相对 0.4.0-beta）

### Human Consent Gate（默认 strict）

- 人在最近 2 秒内有输入时，需要焦点的 UIA 动作不再静默抢前台：先返回可重试的 `USER_ACTIVE`（attempts / max_attempts / retry_after_ms）。
- 连续 3 次被挡后创建 consent 请求，返回 `AWAITING_USER`（一次性 `consent_id` + `expires_at`）；托盘弹出非激活的 Allow/Deny 窗，15 秒倒计时，不抢焦点。
- 无人响应时倒计时自动放行；`USER_DENIED` 为终态；`CONSENT_EXPIRED` 需重新请求。
- 票据绑定具体 target/action/element、一次性、授权后 30 秒过期；服务端只授权，动作仍由 Agent 执行，不会重放旧动作。
- 窗口消息与 CDP 路径永不经过门禁。

### gs doctor 环境自检 + 排障文档

- `gs doctor [--json] [--bundle path]`：检查 OS 版本/架构、Edge 路径与版本、WGC 可用性、虚拟屏/停车点、state 目录与 journal 健康度、status.json 端点可达性；每项带 detail 与下一步 hint，任一 fail 时退出码 1。
- `--bundle` 输出脱敏报告（用户名 → `%USER%`、token → `%REDACTED%`），可直接贴 issue。
- 新增 [doc/19-Troubleshooting](19-Troubleshooting.md)：现象速查表、错误码表、服务环境注意事项、issue 前 bundle 流程。

### 焦点安全（0.4.1-dev）

- 原生元素动作改为窗口消息优先（`BM_CLICK`/`WM_SETTEXT`），不激活停泊窗口。
- 无 HWND 的 WPF/UWP 控件走 UIA 回退，执行后由 `FocusGuard` 恢复原前台。

### 性能

- 窗口事实缓存、进程名 30 秒 TTL、点选场景去掉重复 UIA 树遍历、`click_element(name)` 去掉重复元素解析；本地微基准 `list_windows` 29.15 → 1.04 ms/op。

## 验证

- 测试 **34/34**；构建 0 warning / 0 error；`dotnet format --verify-no-changes` 通过。
- `gs doctor` 本机 6 项实测（os OK / edge WARN / wgc OK / display OK / state_dir OK / status INFO）。
- 发布包自检：`gs version` 输出 `GhostScreen 0.1.0`；MCP `initialize` 的 clientInfo 版本为 `0.1.0`；stdio 冒烟返回 21 工具。

## 已知限制

- 混合 DPI/双屏、锁屏/唤醒未测（单屏）。
- 24h soak、4 target 混沌（锁屏/切桌面/断网）未完成。
- 托盘无暂停/恢复、登录自启；VDD、干净机器、代码签名未完成。
- 安装脚本 unsigned，SmartScreen 可能提示。
- UWP 协商门、多 Agent 排队/允许 5 分钟未实测。

## 从 0.4.0-beta 升级

- 替换 `mcp/`、`cli/`、`tray/` 三个目录；MCP 工具签名不变（21 工具）。
- 行为变化：UIA 焦点动作默认走 strict 协商门；需要旧行为时可调整 `InteractionPolicy`（取值见 doc/03）。
- 建议升级后先跑 `gs doctor` 确认环境。
