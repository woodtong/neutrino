## 新增（相对 0.1.0）

### 窗口可见性：`agent-only` 与 `end_turn`（P4-12，21 → 25 工具）

- `attach_window` 支持 `visibility`：
  - `return-to-user`（默认）：停泊的窗口在 `close_target`/`end_turn` 时原样还给用户。
  - `agent-only`：整个生命期停在屏外，释放时原地 `WM_CLOSE` 关闭，永不回到桌面；若应用在 4 秒宽限内拒绝关闭，则还原窗口并返回 `WINDOW_CLOSE_REFUSED` 警告。
- 新增四个工具：`show_to_user`（把窗口还给用户，幂等）、`park_window`（重新停泊，需 `confirm`）、`set_visibility`（只改归属不移窗口）、`end_turn`（一轮结束时批量归还 `return-to-user` 窗口，target 保持附着）。
- Target DTO 增加 `visibility` 与 `zone`；崩溃恢复语义不变（journal 在还原时移除、停泊时重加）。

### 协商窗：内容自适应 + 可见倒计时 + 延时

- 布局改为 `TableLayoutPanel` 自适应行高，按 `GetPreferredSize` 定高，固定像素乘 `DeviceDpi/96`：不再有 380×154 比内容矮 14px 的重叠，150% 缩放下也不裁切；长标题换行时卡片变高。
- 倒计时除了秒数，还显示一条收缩进度条；新增「延时」按钮，**由服务端裁决**：每次把截止时间推后 30 秒，最多 3 次，客户端以返回的 `remaining_ms` 为准而不是本地时钟。延时只推迟待决票的截止时间，不改变「允许后 30 秒内一次性消费、绑定 target/action/element」的语义。

### 协商窗改为「请求打断」

- 票据本来就是“Agent 在门禁处连续被挡”后才创建的，窗口文案随之改成申请**打断**的权限：`{agent} 想在「{target}」上{动作}` / `这一步必须先取得前台焦点，等于打断你正在做的事` / `你正在：…` / `若同意，请先停下手上的{输入|点击|操作}；一秒后焦点自动还给你`。
- 按钮为「允许打断｜延时｜拒绝」，倒计时文案为「若未操作，N 秒后自动放行这次打断」。

### 门禁活动细分（不读输入内容）

- `HumanActivityProbe` 返回快照：`activity` 四态 `typing` / `pointing` / `active` / `none`、前台窗口标题、caret 与菜单、移动缩放位、`idle_ms`。
- `typing` 是“前台线程有 caret + 阈值内有输入”的**推断**，不是读键盘；门禁自始至终不挂钩子、不记录输入内容。
- 三个新字段（`activity`、`activity_detail`、`interruption`）沿 `USER_ACTIVE`、`AWAITING_USER`、MCP 错误体和 `/api/status` 的 `consents[]` 传播；`idle_ms` 让 Agent 能区分“人刚停手”和“人已走开”。

### 通知抽成独立模块（`GhostScreen.Notifier`）

- 协商窗与故障提示移出 MCP 进程：`src/GhostScreen.Notifier` 是独立 WinExe，宿主命名管道 `GhostScreen.Notifier`（一行 JSON 请求 / 一行 JSON 回复），消息分 `toast` 与 `prompt` 两类，prompt 串行排队。
- 两条宿主路径：托盘在跑时由托盘宿主服务（复用 `NotifyIcon`）；托盘不在时调用方按需拉起 exe。通知失败只返回 `null`，绝不改变触发它的工具结果。
- 文案统一在 Core（`ConsentPromptCopy`/`NotifierText`），两条路径逐字一致；通知跟随系统 UI 语言（非中文回退英文，`GHOSTSCREEN_NOTIFY_LANG=zh|en` 可覆盖）。
- 静默事件现在都会说话：`user-active:{target}`（第二次被挡时的“松手提醒”，60 秒冷却）、`consent:{id}`、`degraded:{target}`（`TARGET_HUNG`）、`close-refused:{target}`、`recovery-restored`、`mcp-down`、`mcp-fatal`。
- 卡片仍以 `ShowWithoutActivation` + `WS_EX_NOACTIVATE|WS_EX_TOOLWINDOW` 弹出，不抢键盘；位置取前台窗口所在显示器（退鼠标所在屏、再退主屏），`DpiChanged` 时重排。托盘轮询在状态端点消失时退到 5 秒，读通即回 2 秒。

## 已知限制

- 混合 DPI/双屏、锁屏/唤醒仍未实测（本机单屏；窗口落点与 `DpiChanged` 逻辑只有预览渲染与单元级验证）。
- 24h soak、4 target 混沌（锁屏/切桌面/断网）未完成。
- `typing` 依赖前台线程有 caret：浏览器常有，自绘编辑器会退化成 `active`（宁可少说也不误判）。
- 通知只有中英两套；托盘菜单/状态文字仍是中文，与通知语言可能不一致（有意限制）。
- 英文长句会让卡片变高（约 570×317），靠换行消化，不截断也不省略。
- 托盘无暂停/恢复、登录自启；VDD、干净机器、代码签名未完成；安装包 unsigned，SmartScreen 可能提示。
- UWP 协商门、多 Agent 排队/允许 5 分钟未实测。

## 从 0.1.0 升级

- 替换 `mcp/`、`cli/`、`tray/` 三个目录；**新增** `GhostScreen.Notifier.exe` 随 `tray/` 一起发布，托盘会自动宿主它，无需单独启动。
- 工具签名向后兼容：21 → 25，只增不改；`attach_window` 的 `visibility` 默认 `return-to-user`，旧调用行为不变。
- 行为变化：协商窗文案改为“请求打断”，并多了「延时」键；`USER_ACTIVE`/`AWAITING_USER` 的错误体多了 `activity`、`activity_detail`、`interruption`、`idle_ms`（旧客户端忽略即可）。
- 建议升级后先跑 `gs doctor` 确认环境。
