# 中微子（Neutrino）技术栈

> 版本：0.5.0-dev ｜ 日期：2026-10-25
> 本文描述**实际依赖与实现技术**，不是候选方案。选型理由和实测限制见 `doc/01`、`doc/02`、`doc/16`。

## 1. 总览

中微子是一个 **C# / .NET 8** 的 Windows 11 本地程序：

- 原生窗口：**PrintWindow 离屏捕获** + **UIA 观测/动作** + **Win32 窗口消息**
- 可见窗口/VDD：**Windows.Graphics.Capture（WGC）+ Direct3D11**
- 网页：**无头 Edge + Chrome DevTools Protocol（CDP）**
- Agent 接口：**手写 MCP stdio（JSON-RPC 2.0）**
- 人类界面：**WinForms 托盘** + 手写 loopback HTTP 状态页
- 运行时不依赖第三方 NuGet 包；只使用 BCL、Windows SDK 投影和 Edge 自带协议

## 4. 捕获技术

### 4.1 PrintWindow（离屏主路径）

- `PrintWindow(hwnd, hdc, PW_RENDERFULLCONTENT)` 让目标把完整内容画到内存 DC。
- GDI `CreateCompatibleDC` / `CreateCompatibleBitmap` / `SelectObject` / `BitBlt` 取像素。
- 目标 DPI-unaware 时：在 **DPI-unaware 线程上下文**捕获，再用 `StretchBlt(HALFTONE)` 缩放到物理客户区，消除黑边。
- 6s 超时 + 专用后台线程；`IsHungAppWindow` 在 `Describe` 前检查，挂起窗口直接拒绝，不返回旧帧。
- 空白/纯色检测、帧 hash、稳定性等待。

### 4.2 WGC + D3D11（可见窗口/VDD）

- `Windows.Graphics.Capture`（WinRT）按窗口/显示器取帧。
- `Direct3D11` 设备、`Direct3D11CaptureFramePool`、`GraphicsCaptureSession`。
- 帧转 BGRA 后交给 `Windows.Graphics.Imaging.BitmapEncoder` 编码 PNG。
- **只用于可见窗口或虚拟显示器**：完全离屏的 WGC 会冻结在最后一帧（P0 实测 1/20 唯一 hash）。

### 4.3 PNG

- `Windows.Graphics.Imaging` + `Windows.Security.Cryptography`（WinRT），不依赖 `System.Drawing`。
- 截图通过 MCP `image` content 以 base64 PNG 返回。

## 5. 观测与输入

### 5.1 UIA

- `System.Windows.Automation`（`UIAutomationClient`，由 `UseWPF` 带入）。
- 扁平化 `Snapshot`：ref/role/name/AutomationId/bounds/enabled/focused/patterns；epoch 过期返回 `ELEMENT_STALE`。
- 语义动作：`Invoke`、`Toggle`、`SelectionItem.Select`、`ExpandCollapse`、`ValuePattern.SetValue`；坐标点击可用 `AtPoint` 在单 HWND 表面按屏幕点找最小可执行元素。
- UIA 观测只读；UIA 动作可能激活目标窗口，由 Human Consent Gate / `FocusGuard` 管理。

### 5.2 窗口消息

- `SendMessage`/`PostMessage`：`BM_CLICK`、`WM_LBUTTONDOWN/UP`、`WM_MOUSEMOVE`、`WM_MOUSEWHEEL`、`WM_SETTEXT`、`WM_KEYDOWN/UP`、`WM_CHAR`。
- `MapVirtualKey` 生成 scan code，扩展键设置 lParam bit 24。
- 只对 HWND 子控件/经典 Win32/WinForms 可靠；Chromium/Electron 忽略消息，走 CDP。

### 5.3 焦点与人类活动

- `GetForegroundWindow` / `SetForegroundWindow` / `AttachThreadInput` / `GetWindowThreadProcessId`。
- `FocusGuard`：最多等 500ms 观察激活，恢复后做 100ms 稳定校验；不用 `SwitchToThisWindow`。
- `GetLastInputInfo`：最近 2 秒有人类输入时，strict 模式进入 Human Consent Gate。
- Human Consent Gate：尝试计数、15s 倒计时、一次性 `consent_id`、状态端点/托盘协商窗。
- 默认**不使用 SendInput**；不移动真实光标、不写剪贴板。

## 6. 网页 / CDP

- Edge 启动：`--headless=new`、`--remote-debugging-port=0`、`--user-data-dir` 私有临时 profile；端口从 `DevToolsActivePort` 读取。
- 进程启动用 `CreateProcessW`：可执行文件走固定安装路径白名单，命令行参数固定/受控，无 shell；关闭时杀进程树并删 profile。
- CDP：`ClientWebSocket` + JSON-RPC；使用 `Page`、`Runtime`、`DOM`、`Network`、`Emulation`、`Input` 域。
- 典型调用：`Page.captureScreenshot`、`Emulation.setDeviceMetricsOverride`、`Input.dispatchMouseEvent`、`Input.insertText`、`Input.dispatchKeyEvent`、`Runtime.evaluate`、`DOM.getDocument`、`Network`/console 事件。
- `attach_cdp` 连接已有 Chromium/Electron 调试端口（VS Code 实测），只 detach，不杀外部进程。
- 不使用 Playwright、Puppeteer、ChromeDriver 或 WebView2。

## 7. Agent 接口（MCP）

- **手写 MCP stdio**：`initialize` / `tools/list` / `tools/call`，JSON-RPC 2.0。
- 21 个工具：窗口/网页/target 生命周期、截图、observe、点击、坐标点击、滚动、拖拽、按键、set_text、导航、视口、console、network、get_html、close。
- 返回：文本 JSON、PNG `image` content、结构化错误（`code`、`message`、`retryable`、`attempts`、`consent_id`、`expires_at` 等）。
- 无官方 MCP SDK 运行时依赖；官方 SDK 仅用于客户端联调测试。
- 协商协议：`USER_ACTIVE` → `AWAITING_USER` → Agent 带 `consent_id` 重试；`USER_DENIED` / `CONSENT_EXPIRED` 为终止/重申请状态。

## 8. 本地控制面与人类界面

- **状态端点**：原始 `TcpListener` + 手写 HTTP/1.1，仅 `127.0.0.1`；无 ASP.NET Core、无 Http.sys、无管理员 URL ACL。
- 每个进程随机 token；`X-GhostScreen-Token` 或 query token；端点信息写入 `%LOCALAPPDATA%\GhostScreen\status.json`。
- 页面：原生 HTML/CSS/JS（`fetch` 轮询），target 卡片、缩略图、急停、单 target 关闭。
- 托盘：`GhostScreen.Tray.exe`（WinForms `NotifyIcon`），每 2s 轮询状态端点；per-target 列表/关闭、打开状态页、急停、退出。
- 协商窗：WinForms 非激活小窗（`ShowWithoutActivation` + `WS_EX_NOACTIVATE` + `WS_EX_TOOLWINDOW`），允许/拒绝 + 15s 倒计时；不抢焦点。

## 9. 状态与存储

- `System.Text.Json`；无数据库。
- `%LOCALAPPDATA%\GhostScreen\state\targets.json`：崩溃恢复 journal；临时文件 + 原子替换；损坏文件移到 `.corrupt-*`。
- `%LOCALAPPDATA%\GhostScreen\status.json`：MCP 状态端点 URL/token/port/pid；退出删除。
- `%LOCALAPPDATA%\GhostScreen\web-profiles\<guid>`：每个 web target 的临时 Edge profile；关闭时删除。
- 截图/证据默认不写盘；MCP 以 image content 返回；spike/测试显式写 `spike/out`。

## 10. 测试与 CI

- 测试 runner 是**自写零依赖 runner**（没有 xUnit/NUnit/MSTest）；断言失败即非零退出。
- 32 项测试：原生/web MCP 全链路、焦点不变量、WPF UIA 回退、ConsentManager/严格协商门、外部 CDP attach、死目标、崩溃恢复、挂起降级、WGC 连续帧、DPI/DPI-unaware、状态端点/状态页、URL/Edge 白名单、PNG 等。
- `tests/FixtureApp`：WinForms 确定性夹具；`tests/GhostScreen.Tests` 内还有 WPF 夹具（验证无 HWND 的 UIA 路径）。
- `tests/GhostScreen.WebStress`：100 次 open/capture/close 泄漏压力；`tests/GhostScreen.Soak`：多 target 浸泡。
- GUI 相关测试默认 opt-in：
  - `GHOSTSCREEN_VISIBLE_TESTS=1`（WGC 必须可见窗口）
  - `GHOSTSCREEN_UIA_TESTS=1`（WPF UIA/协商门会短暂激活前台）
- GitHub Actions：`windows-2022`，`dotnet restore` → `dotnet format --verify-no-changes` → Release build → 测试 runner；Dependabot；CodeQL 仅在仓库公开时运行（私有仓库没有 GHAS 时 SARIF 上传会失败）。

### 10.1 性能基线（2026-10-25，本机）

FixtureApp 离屏、Release、同一进程预热后测量（200 次；`List` 为 50 次）：

| 操作 | 优化前 | 优化后 | 说明 |
|---|---:|---:|---|
| `WindowEnumerator.List`（50 次） | 29.15 ms/op | 1.04 ms/op | 进程名 30s TTL 缓存；首次调用仍冷 |
| `Children`（200 次） | 0.31 ms/op | 0.17 ms/op | 子窗口改用 `ChildrenLite`，不再查进程/DPI/DWM |
| `TryClickChildAtScreenPoint`（200 次） | 0.32 ms/op | 0.18 ms/op | 同上 |
| `ClickClientPoint`（200 次） | 2.10 ms/op | 1.60 ms/op | 含 3 次窗口消息，主要成本在目标线程 |

相关优化：`ChildrenLite` 轻量子窗口枚举、进程名短 TTL 缓存、WPF/UWP 坐标点击只走一次 UIA 树找元素、`ClickElement(name)` 跳过重复元素解析。

这是本机微基准，不等同于所有应用的 p50；真实应用仍受目标 UI 线程、PrintWindow、DPI 和 UIA provider 影响。

## 11. 打包与分发

- `scripts/publish.ps1`：`dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true`，分别生成 `mcp/`、`cli/`、`tray/`。
- 产物：`artifacts/GhostScreen-<version>-win-x64.zip` + `.sha256`；当前约 172 MB（self-contained 单文件）。
- `scripts/install.ps1`：复制到 `%LOCALAPPDATA%\GhostScreen\app`、创建开始菜单托盘快捷方式；`-Uninstall` 可逆；不改 PATH/MCP 配置。
- 未签名；不捆绑驱动/服务；无遥测、无云依赖。

## 12. 明确未采用 / 不依赖

- 不用 WGC 做离屏实时（会冻结）。
- 不用 Playwright/Puppeteer/ChromeDriver/Selenium（网页直接 CDP）。
- 不用 ASP.NET Core / Http.sys / WebSocket 做状态端点（原始 TCP + HTTP/1.1）。
- 不用 `InjectSyntheticPointerInput` 按窗口注入（它不支持 hwndTarget）。
- 默认不用 SendInput；不移动真实光标、不写剪贴板。
- 不注入 DLL、不挂钩 API、不装驱动、不依赖 IddCx VDD。
- 不用第三方测试框架、数据库、消息队列、云服务。
- 运行时不依赖任何 NuGet 包；只有 BCL + Windows SDK/WinRT 投影。
