## 这个版本能做什么

- Windows 11 本地运行，不联网、无遥测。
- 通过 MCP stdio 给 Agent 提供：
  - 列出窗口、停泊指定窗口；
  - 截图（PNG image content + 元数据，默认客户区裁剪）；
  - UIA 观测（epoch + ref）；
  - 按 ref/name 点击、客户区坐标点击、滚轮、拖拽、按键；
  - set_text、close_target、close_all。
- 目标窗口停泊到物理屏之外；不抢前台（普通 Win32/WinForms 已验证）；EOF/断连还原。
- 附带 `GhostScreen.Cli.exe`：`version/state/list/shot`。

## 快速开始（MCP）

```json
{
  "mcpServers": {
    "ghostscreen": {
      "command": "C:\\path\\to\\GhostScreen-0.1.0-p0\\mcp\\GhostScreen.Mcp.exe",
      "args": []
    }
  }
}
```

工作流：

```text
list_windows → attach_window(confirm=true) → screenshot / observe
→ click_element(ref) / click(x,y) / scroll / drag / key / set_text
→ close_target / close_all
```

更多客户端配置见 `docs/MCP-CLIENTS.md` 或 `doc/08-MCP客户端配置.md`。

## 已知限制（alpha）

- 只支持原生窗口 + UIA；Web/CDP target 尚未接进 MCP。
- MCP 是单进程：没有 daemon/HTTP/多客户端；崩溃不还原（仅 EOF/close_all）。
- VS Code/Electron 的 PrintWindow 只有 chrome；需要 CDP，当前未接 MCP。
- UWP 启动可能抢前台；不能承诺无焦点。
- 键盘是消息级；复杂 IME/快捷键需应用级验证。
- DPI-unaware 遗留应用、多显示器、VDD 未完成验证。
- 没有代码签名；SmartScreen 可能提示。
