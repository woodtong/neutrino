## 本版新增

### 网页目标（真正零窗口）

- `open_web { url, width, height, device_scale_factor, mobile }`：启动私有**无头 Edge**，独立临时 profile，不弹窗、不碰用户浏览器配置。
- 目标 URL 不进入命令行（固定从 `about:blank` 启动，再经 CDP 导航），只允许 http/https/file/about。
- `screenshot`：CDP 视口截图，返回 PNG image content + 元数据（`backend=cdp`、设备像素尺寸、CSS 尺寸、DPR）。
- `observe`：DOM 可交互元素（button/a/input/textarea/select/role=button/contenteditable/onclick），带 ref、role、name、稳定 CSS selector、bounds（CSS px）、enabled。
- 输入/动作：`click`、`click_element`（ref 点击时重新取元素中心）、`set_text`（React 兼容 native setter + input/change）、`key`（Ctrl/Shift/Alt/Meta）、`scroll`（合成鼠标手势）、`drag`。
- 页面诊断：`console`（最近 500 条）、`get_html`（整页或 selector）。
- 响应式：`viewport`（宽度/高度/DPR/移动端模拟）、`navigate`。
- 生命周期：`close_target` 执行 `Browser.close` → 杀进程树 → 删除临时 profile；`close_all`/EOF 清理全部。

### 统一目标模型

- 原生窗口与网页共用同一套 MCP 工具；target 的 `kind` 为 `app` 或 `web`。
- 原生-only 或 web-only 用法错误返回 `TARGET_KIND_MISMATCH`。
- 版本号集中到 `src/GhostScreen.Core/ProductInfo.cs`；发布脚本自动读取。

## 快速开始

### 1. 配置 MCP 客户端

```json
{
  "mcpServers": {
    "ghostscreen": {
      "command": "C:\\path\\to\\GhostScreen-0.2.0-p0\\mcp\\GhostScreen.Mcp.exe",
      "args": []
    }
  }
}
```

Claude Code：

```bash
claude mcp add ghostscreen -- "C:\path\to\GhostScreen-0.2.0-p0\mcp\GhostScreen.Mcp.exe"
```

### 2. 网页视觉验证

```text
open_web { url: "http://localhost:3000", width: 1280, height: 800 }
screenshot { target_id }
viewport { target_id, width: 390, height: 844, device_scale_factor: 2, mobile: true }
screenshot { target_id }
close_target { target_id }
```

### 3. 原生窗口

```text
list_windows
attach_window { hwnd: "0x1234", confirm: true }
screenshot { target_id }
observe { target_id }
click_element { target_id, ref: "e1" }
close_target { target_id }
```

## 已验证（本机，Windows 11 26200）

- 构建 0 warning / 0 error；`dotnet format --verify-no-changes` 通过。
- 测试 **14/14**，含真实无头 Edge 全链路：
  - 打开 900×700 → 截图（900×700）→ observe → ref 点击 → 坐标点击 → 中文 `set_text("mcp 世界")` → `CTRL+S` → 拖拽 → 滚动 → console 捕获 `boom` → 390×844@2（截图 780×1688）→ navigate → close。
  - 关闭后浏览器进程退出；`%LOCALAPPDATA%\GhostScreen\web-profiles` 为空。
- 发布版二进制 stdio 冒烟：`initialize` 返回 0.2.0-p0；`tools/list` 返回 18 工具；`open_web` 创建 web target；`close_all` 关闭 1 个 target 并打印 “all targets restored”。
- 启动安全：只允许固定安装根（Program Files (x86) / Program Files / LocalAppData）下的 `msedge.exe`；参数经 `ArgumentList` 传递、`UseShellExecute=false`、无 shell；目标 URL 不进入启动参数（固定 about:blank，导航走 CDP）。
- 截图 `spike/out/web-shot.png` 经图像复核：按钮、状态、placeholder、绿色拖拽块均正确，无黑边/裁切。

## 已知限制（alpha）

- 网页：无整页截图/元素裁剪、network idle、Network 域、多视口 snapshot。
- 只发现 Edge，无 Chrome 回退；无头 UA 仍可能被站点识别。
- 未做 100 次开关泄漏压力；未在真实 MCP 客户端（ZCode/Claude/Cursor）与干净机器验证。
- 原生：per-target worker 未复用；WGC 仅可见窗口；UWP 可能抢焦点；DPI-unaware 遗留应用有黑边。
- 无独立 daemon/HTTP/多客户端；MCP 单进程；崩溃不还原（只有 EOF/close_all）。
- 未签名。

## 从 0.1.0-p0 升级

- 直接替换可执行文件；配置不变。
- 新增 5 个工具（open_web/navigate/viewport/console/get_html），原生工具签名不变。
- 旧版只支持原生窗口；需要网页时用 `open_web`，不要 attach 用户的浏览器窗口（会移动它）。
