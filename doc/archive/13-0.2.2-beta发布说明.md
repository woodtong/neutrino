## 这个版本能做什么

- **网页**：私有 headless Edge，零窗口；截图（视口/整页/裁剪）、DOM 观测与 ref 点击、中文输入、组合键、滚动、拖拽、视口切换、导航、console、network、多视口 snapshot + 横向溢出定位。
- **原生窗口**：停泊到物理屏之外；PrintWindow 实时截图；UIA 观测/Invoke/SetValue；坐标点击/滚动/拖拽/按键走窗口消息；默认不抢焦点、不动光标。
- **生命周期**：关闭 target 还原窗口/关浏览器/删 profile；EOF 或 `close_all` 清理全部。
- **稳定性**：100 次 `open_web → screenshot → close` 压力 0 失败，句柄/内存封顶，profile 0。

完整启动配方与兼容矩阵见 [doc/12-Recipes.md](12-Recipes.md)（发布包内未包含；仓库/发布页提供）。

## 已知限制（beta）

- **未做与有头 Edge 的像素 diff**：headless 与 headed 使用同一 Blink 引擎，但本机未做逐像素对比；该项推迟到 P4 保真度任务，并会要求一个可见的 headed 实例（可能打扰桌面）。
- **VS Code/Electron 的 CDP 尚未接入 MCP**：目前只能 PrintWindow chrome + UIA；完整输入需要后续“连接已有 CDP 端点”工具。
- **UWP 焦点不稳定**：Calculator/设置可能抢前台，不能承诺零打扰。
- **DPI-unaware 遗留应用**：黑边/缩放，v0.2 不支持。
- 未在真实 MCP 客户端（ZCode/Claude/Cursor）与干净机器验证；未签名。
- 整页截图受 16384px 限制；network 不含请求/响应体；跨 iframe 覆盖有限。
- 无独立 daemon/HTTP/多客户端；MCP 单进程；崩溃不还原（只有 EOF/close_all）。
