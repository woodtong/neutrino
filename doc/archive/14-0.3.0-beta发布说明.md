## 新增

### 崩溃恢复

- 每个 target 写入 `%LOCALAPPDATA%\GhostScreen\state\targets.json`（临时文件原子替换）。
- 下次启动校验 hwnd、pid、窗口类后 `SetWindowPlacement` 还原；web 孤儿按 pid + 启动时间 + 进程名清理并删 profile；24h 以上陈旧 profile 清扫；损坏 journal 移到 `.corrupt-*`。
- journal 写失败返回 `STATE_WRITE_FAILED` 并撤销本次 attach/open。

### 挂起应用

- `CaptureEngine` 在 `WindowEnumerator.Describe` **之前**检查 `IsHungAppWindow`，命中立即 `TARGET_HUNG`，不把 DWM 表面上的旧帧当成功。
- `attach_window` 在移动窗口前拒绝挂起窗口，避免 `SetWindowPos` 卡死。
- 连续 2 次 `CAPTURE_TIMEOUT` 也降级；之后 capture/observe/input 快速失败，`close` 仍可还原。

### 状态页

- MCP 进程内 loopback 状态端点（原始 TCP，无 Http.sys/管理员）；每次启动随机 token。
- `GET /`：target 卡片（kind/state/degraded_reason）+ 5 秒刷新缩略图；`GET /api/status`；`GET /api/screenshot?target_id=`；`POST /api/panic`。
- URL/token/port/pid 写入 `%LOCALAPPDATA%\GhostScreen\status.json`，MCP stderr 打印，退出删除。

### 托盘

- `tray/GhostScreen.Tray.exe`（单实例）：每 2 秒轮询状态端点，tooltip 显示版本/target 数；菜单打开状态页、急停（确认后 close_all）、退出。
- 不持有 target；MCP 退出后显示“未运行”。

### Soak harness

- `tests/GhostScreen.Soak`：可配置时长/间隔，循环 native capture/observe + web open/capture/close，按预热后基线统计句柄/私有内存/profile。
- 3 分钟预跑：29 轮、29 个 web target、0 失败；预热后句柄 550→556（+6）、私有内存 38→40MB（+2）、profiles 0，**PASS**。
- 4 目标预跑（2 native + 2 web）：24 轮、48 个 web target、0 失败；句柄 563→572（+9）、私有内存 49→45MB（-4）、profiles 0。
- 24h 运行：`dotnet run --project tests/GhostScreen.Soak -c Release -- --minutes 1440 --interval 30 --output soak-24h.jsonl`（尚未在本机跑满）。

- `WindowInfo.DpiAwareness`：`list_windows`/target DTO 输出 `dpi_awareness`；`Unaware` 目标带 `DPI_UNAWARE` warning（捕获黑边修复仍未做）。
- 官方 `@modelcontextprotocol/sdk` 1.32.2（Node 22）stdio 联调通过：initialize、20 工具、open_web、PNG image content、observe、close_all。

## 验证

- 构建 0 warning / 0 error；`dotnet format --verify-no-changes` 通过。
- 测试 **24/24**：原生/web MCP 全链路、崩溃恢复、孤儿 Edge 清理、真实挂起拒绝、降级状态机、WGC 可见、多屏负坐标布局、DPI awareness、状态端点鉴权/截图/急停、状态页无头 Edge 渲染 + image-viewer 复核。
- 安静环境不变量重测：`humanInput=false`，前台/光标/剪贴板不变，3 帧哈希不同，`pass=true`。
- 发布版冒烟：20 工具、`open_web`、`close_all`、状态页 URL、`status.json` 退出删除；托盘由发布脚本一并打包。

## 已知限制

- 托盘没有 per-target 列表、暂停/恢复、登录自启；降级态未单独展示。
- 状态页 0.2fps 缩略图，不是 2–5fps；无 SSE/连续帧；token 在 URL 中，仅本机。
- 没有独立 daemon/多客户端；状态页与托盘都依赖 MCP 进程。
- 多屏/混合 DPI 未实测；DPI-unaware 遗留应用黑边未解决。
- 24h soak 尚未跑满；真实 MCP 客户端（ZCode/Claude/Cursor）与干净机器未验证；未签名。
- 整页截图 16384px 上限；network 不含请求/响应体；跨 iframe 覆盖有限。
